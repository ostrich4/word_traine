# Word Trainer

Мобильный офлайн-тренажёр иностранных слов с интервальными повторениями.
Проект выполнен на **Flutter / Dart** как альтернативный декларативный стек для лабораторной работы по разработке приложений для iPhone и iPad.

## Возможности

- личные словари пользователя;
- добавление иностранных слов и переводов;
- локальное хранение в SQLite;
- сессия интервальных повторений с четырьмя оценками: **Снова / Тяжело / Нормально / Легко**;
- автоматический расчёт даты следующего повторения;
- недельная статистика изученных слов в виде диаграммы `fl_chart`;
- количество слов, ожидающих повторения;
- дополнительный импорт демонстрационных слов через REST API;
- после импорта все слова доступны офлайн;
- запуск на Android/iOS и в Chrome/Web.

## Архитектура

В приложении используется **MVVM**:

- **Model / Data** — `DatabaseHelper`, SQLite-таблицы и модели из `lib/models`;
- **ViewModel** — `HomeViewModel`, `WordsViewModel`, `RepetitionViewModel` на базе `ChangeNotifier`;
- **View** — экраны Flutter, которые подписываются на изменения ViewModel через `AnimatedBuilder`.

Основные таблицы базы данных:

- `dictionaries` — словари;
- `words` — слова и переводы;
- `progress` — коэффициент сложности, интервал, число успешных повторений и дата следующего повторения;
- `study_sessions` — история ответов для построения статистики.

## Интервальные повторения

| Оценка | Следующее повторение |
| --- | --- |
| Снова | сразу, в текущей сессии |
| Тяжело | через 1 день |
| Нормально | через 3 дня |
| Легко | через 7 дней |

При последующих ответах интервал увеличивается с учётом предыдущего интервала и `ease_factor`. Значение `ease_factor` не может стать меньше `1.3`.

## REST API

Кнопка с иконкой облака на экране слов выполняет HTTP GET к `data/demo_words.json` в этом репозитории. Сетевой слой реализован в `lib/services/remote_words_service.dart`. Полученные слова сохраняются в SQLite, поэтому REST используется только для импорта, а не для основной работы приложения.

## Используемые технологии

- Flutter / Dart
- Material 3
- SQLite (`sqflite`)
- `sqflite_common_ffi_web` для Web
- `fl_chart`
- `http`
- `ChangeNotifier` / `AnimatedBuilder`

## Запуск

После клонирования репозитория при необходимости можно восстановить стандартные платформенные каталоги Flutter командой:

```bash
flutter create .
```

Затем установить зависимости:

```bash
flutter pub get
```

Для Web-версии необходимо один раз подготовить SQLite Web-файлы:

```bash
dart run sqflite_common_ffi_web:setup
```

Запуск в Chrome:

```bash
flutter run -d chrome
```

Запуск на Android Emulator:

```bash
flutter run
```
